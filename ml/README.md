## What you get

This repository contains the technical core you are responsible for:

- dataset
- preprocessing
- feature encoding
- model training
- evaluation
- saved ML model
- prediction service
- FastAPI
- Streamlit demo
- safety/guidance layer
- evaluation plots
- dataset documentation
- optional path to DDXPlus

## Important scientific limitation

The included CSV is a SYNTHETIC DEMONSTRATION DATASET generated by code.
It is not a medically validated dataset.

For a real research claim, replace it with a properly licensed and documented dataset.
A strong candidate is DDXPlus, a research dataset released by Mila/IQIA under CC-BY:
https://github.com/mila-iqia/ddxplus

Do not claim that demo accuracy represents clinical performance.

# 1. Installation

Create an environment:

Windows:
```bash
py -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

Install:
```bash
pip install -r requirements.txt
```

---

# 2. Train the model

From the project root:

```bash
cd scripts
python train.py
```

This creates:

```text
artifacts/
├── careai_model.joblib
├── metrics.json
├── classification_report.json
├── confusion_matrix.npy
├── class_names.json
└── feature_importance.csv
```

Then run:

```bash
python evaluate.py
```

It additionally creates:

```text
artifacts/
├── feature_importance.png
└── confusion_matrix.png
```

# 5. Your technical explanation to judges

### Dataset
"We created a reproducible prototype dataset with symptom vectors and condition labels for validating the software pipeline. For a production/research version we would replace the demo dataset with a properly licensed medically documented dataset such as DDXPlus."

### Preprocessing
"Symptoms are normalized into a canonical vocabulary and represented using multi-hot encoding. Each symptom becomes a binary feature."

### Training
"We use a stratified train/test split and a class-balanced Random Forest classifier. The model is trained only on the training partition."

### Evaluation
"We evaluate accuracy, macro precision, macro recall, macro F1 and weighted F1. We also inspect the confusion matrix and feature importance."

### API
"FastAPI exposes a /predict endpoint so the ML model is separated from the user interface. This allows a web/mobile frontend to consume the same inference service."

### Explainability
"We provide model-level feature importance and explicitly describe it as an association learned by the model, not a causal medical explanation."

### Safety
"The ML prediction is separated from a rule-based red-flag layer. This is intentional: a classifier should not be responsible for emergency triage."

# 7. What NOT to say

Do not say:
- "Our AI diagnoses patients."
- "82% confidence means the patient has the disease."
- "Our model is medically accurate."
- "The model replaces doctors."

Say:
- "prototype decision-support system"
- "learned symptom-pattern prediction"
- "model probability"
- "not clinically validated"
- "designed to assist, not replace clinicians"
