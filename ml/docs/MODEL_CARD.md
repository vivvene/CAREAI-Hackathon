# CareAI Model Card

## Model
Random Forest classifier over multi-hot symptom features.

## Demo performance
- Accuracy: 0.9375
- Macro precision: 0.9386
- Macro recall: 0.9375
- Macro F1: 0.9372
- Weighted F1: 0.9372

## Dataset
Synthetic demonstration dataset with 5998 rows and 20 condition classes.

## Limitations
The dataset was programmatically generated for software demonstration. The performance numbers therefore do not represent real-world clinical performance.

## Intended use
Hackathon prototype and software architecture demonstration only.

## Not intended for
Diagnosis, treatment selection, emergency triage, or clinical decision-making.
